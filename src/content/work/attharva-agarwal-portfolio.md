## The brief

A personal site for Attharva Agarwal, Tomorrow Web’s founder: a student developer who builds websites and digital products and runs two YouTube channels. It needed to present work in progress honestly and be easy to keep up to date.

## What we built

- An editorial, dark design with a serif display face and a single lime accent.
- Featured projects, websites built for others, experiments with honest status labels and a YouTube section that only loads the video player when someone presses play.
- A contact form on Netlify Forms, plus email, GitHub and LinkedIn links.
- A single configuration file that holds all the content, so updates never require touching components — and empty links are never shown as clickable.

## What it shows

The same principles we bring to client sites: clear structure, fast loading, accessibility, and copy that only says what’s true.
